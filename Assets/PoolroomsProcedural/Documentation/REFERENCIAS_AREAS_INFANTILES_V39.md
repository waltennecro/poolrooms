# Referencias del nuevo bioma infantil v39

Se revisaron los 100 JPEG del archivo Areas_infantiles_liminales_100.zip en cinco láminas de 20 imágenes. El bioma anterior permanece separado. Las fotografías y recreaciones son referencias de espacio y materiales; la entrega contiene geometría procedural y texturas originales.

| Imágenes | Rasgos usados en el diseño |
| --- | --- |
| 001–020 | Torres acolchadas de colores, estructuras con redes, escaleras y toboganes dentro de salas grandes. |
| 021–040 | Piscinas de pelotas, tubos huecos, entradas abiertas y puentes. |
| 041–060 | Variación de iluminación interior, techos industriales amplios y juegos de varios niveles. |
| 061–080 | Plataformas, pasos elevados, rampas suaves, redes y zonas de descanso. |
| 081–100 | Recorridos interiores, volumen de las salas, pintura clara y estructuras geométricas abstractas. |

Se reinterpretan proporciones para que un jugador adulto pueda recorrer las estructuras de pie, con pisos separados 3,2 m. No se reproducen personajes, caras ni marcas comerciales. Las referencias no representan renders verificados de esta versión del juego.

El archivo original incluye fuentes de Pinterest y aclara que no concede licencias de reutilización. FUENTES_AREAS_INFANTILES_V39.csv conserva sus enlaces para identificar las referencias; las imágenes no se distribuyen dentro del paquete de Assets. REFERENCIAS_AREAS_INFANTILES_V39.json registra los 100 nombres, tamaños y hashes SHA-256 del archivo recibido.
